# 场景 1：点击纸团展开

在 VS Code 中打开整个“交互课文件夹”，右键 `html/index.html`，选择 **Open with Live Server**。也可以直接用浏览器打开 `html/index.html`，不需要安装依赖。

点击纸团后，纸面沿不等间距的折线逐步翻开，约 1.85 秒完成。折片保持固定长度，四个角稍晚跟随，尾段带轻微回弹。之后保持原图的字体和排版，依次浮现主标题、标题旁小字、人物画面中的两段文字。

约 8.4 秒文字全部出现，完整展示约 1.1 秒后，褶皱从中心向四周逐渐淡去，过渡到新提供的平铺原图。整个交互约 12.3 秒完成，随后可点击“重新展开”从纸团重播。

平铺后，点击海报任意位置，右侧会新增“안내、목차、더보기”和“게임 시작”。原海报保持原来的尺寸、位置和内容，菜单在海报右边独立淡入。窄屏下可以横向滚动查看右侧菜单，海报不会为了菜单而缩小。菜单沿用参考图原字形。支持 Tab 选中画面后按回车显示菜单。点击“重新展开”也会清除菜单状态。

## 文件位置

- `html/index.html`：第一个场景的入口。
- `css/style.css`：页面样式与响应式尺寸。
- `js/main.js`：纸面渲染、点击事件、文字动画。
- `js/paper-motion.js`：固定长度折面的旋开轨迹与阻尼回弹。
- `js/data.js`：离线图片数据，让直接打开 HTML 时也能生成文字图层。
- `js/images/`：这个场景需要的纸团、海报原图、无字底图、平铺海报（`poster-flat.png`）。

在 `js/main.js` 顶部的 `TIMING` 中调整展开时长和文字出现时间，单位为毫秒。所有图层同步使用 `requestAnimationFrame` 驱动，没有中间图片停留。支持系统减少动态效果设置；无法使用 WebGL 的浏览器会使用连续缩放的兼容效果。

最终海报使用所提供的原图，保留原有字形与位置。无字底图沿用之前通过内置图片编辑工具去除文字所得的素材。
